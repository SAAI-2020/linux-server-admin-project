# linux-server-admin-project
Hands-on Linux Server Administration and Monitoring Project using Ubuntu Linux


## Project Overview
This project demonstrates hands-on Linux administration, monitoring, networking, and automation skills using Ubuntu Linux. The project was built to strengthen practical Linux knowledge for Cloud, DevOps, and System Administration roles.

---

## Objectives
- Practice Linux command-line operations
- Learn Linux user and permission management
- Configure and manage Linux services
- Monitor system resources and processes
- Perform basic networking and troubleshooting
- Automate monitoring tasks using Bash scripting

---

## Technologies & Tools Used
- Ubuntu Linux
- Bash Scripting
- Nginx Web Server
- Linux CLI Commands
- Systemctl
- SSH
- Git & GitHub

---

## Tasks Performed

### Linux File & Directory Management
- Created and managed directories and files
- Navigated Linux filesystem using CLI commands
- Practiced file operations such as copy, move, and delete

### User & Group Management
- Created Linux users and groups
- Managed permissions and ownership
- Configured access control using chmod and chown

### Nginx Web Server Administration
- Installed and configured Nginx
- Started, stopped, restarted, and enabled services
- Verified service status using systemctl

### System Monitoring
Monitored:
- CPU usage
- Memory usage
- Disk utilization
- Running processes
- System uptime

### Networking & Troubleshooting
Performed:
- IP address verification
- Connectivity testing
- Port analysis
- Log monitoring and troubleshooting

### Bash Automation
Developed a Bash script to automate:
- System monitoring
- Memory reporting
- Disk reporting
- Network information collection
